# 🐦 앵그리버드 PWA (Angry Birds Vibe Edition)

스마트폰 게임의 전설 **앵그리버드(Angry Birds)**를 웹 표준 기술(`HTML5 Canvas`, `Matter.js` 2D 물리 엔진, `Web Audio API` 신디사이저)과 **PWA(Progressive Web App)**로 완벽하게 재해석한 게임입니다.

---

## ✨ 주요 특징

1. **진짜 물리 엔진 기반 슬링샷 액션 (`Matter.js`)**
   - 고무줄 탄성 당기기, 포물선 궤적 미리보기, 구조물 연쇄 붕괴 및 회전 마찰 시뮬레이션
2. **4종의 개성 넘치는 버드 & 공중 특수 스킬**
   - **레드 (Red)**: 비행 중 클릭/터치 시 주변 구조물을 밀어내는 **충격파(Shockwave)** 발동
   - **척 (Chuck - 노랑새)**: 비행 중 클릭/터치 시 **초고속 터보 가속(Speed Boost)** (나무 관통 특화)
   - **블루 (Blues - 파랑새)**: 비행 중 클릭/터치 시 **3마리로 분신(Triple Split)** (얼음/유리 파괴 특화)
   - **밤 (Bomb - 폭탄새)**: 비행 중 클릭/터치 시 **강력한 대폭발(Explosion)** (돌/석재 파괴 특화)
3. **Web Audio API 실시간 사운드 & BGM 합성 (`src/sound.js`)**
   - 외부 오디오 파일 없이 100% 코드로 합성되는 생생한 효과음(고무줄 당김음, 새 기합 소리, 나무/얼음/돌 파열음, 돼지 꿀꿀 소리, 폭발음, 승리 팡파르)과 경쾌한 배경음악(BGM)
4. **PWA 완벽 지원 (`manifest.json` + `sw.js`)**
   - PC 및 모바일 홈 화면에 **앱 설치** 가능
   - 서비스 워커(Service Worker) 캐싱을 통해 **오프라인 상태에서도 즉시 플레이** 가능

---

## 🚀 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 로컬 웹 서버 실행 (http://localhost:3000)
npm start
```

브라우저에서 `http://localhost:3000`으로 접속하면 바로 게임을 즐기실 수 있으며, 상단 바의 **[📲 앱 설치]** 버튼 또는 브라우저 주소창의 설치 아이콘을 눌러 바탕화면에 앱으로 설치하실 수 있습니다.

---

## 🎮 조작 방법

- **조준 및 발사**: 새총 위의 새를 마우스(또는 터치)로 뒤로 당긴 후 손을 떼면 발사됩니다.
- **공중 특수 스킬**: 새가 날아가는 도중 화면을 **클릭/터치**하거나 **스페이스바(`Space`)**를 누르면 특수 스킬이 발동됩니다.
- **시점 확인**: 화면 우측 상단의 **[🔭 전장 보기]** 버튼으로 돼지 요새 구조를 미리 살펴볼 수 있습니다.
